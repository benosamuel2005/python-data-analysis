# Python Data Analysis — Supermarket Sales

An academic data analysis project developed using Python and Pandas as part of my BSc (Honours) in Computing at Dublin Business School.

## Project Overview

This project focuses on exploring and preprocessing a supermarket sales dataset using Python in a Jupyter Notebook environment.

The objective is to practise essential data analysis techniques, including understanding dataset structure, performing statistical calculations, filtering records and preparing data for further analysis.

## Technologies Used

- Python
- Pandas
- Jupyter Notebook
- Google Colab
- CSV Datasets

## Data Analysis Techniques

- Loading CSV datasets into Pandas DataFrames
- Exploring rows, columns and dataset structure
- Calculating descriptive statistics
- Sorting and filtering records
- Identifying missing values
- Selecting and manipulating columns
- Practising data preprocessing operations

## Project Files

- `Supermarket_Colab.ipynb` — Jupyter notebook containing Python analysis exercises
- Supermarket sales dataset — Data used for analysis and preprocessing

## Skills Demonstrated

- Python Programming
- Data Analysis
- Data Cleaning and Preprocessing
- Pandas DataFrames
- Descriptive Statistics
- Data Manipulation
- Analytical Problem-Solving

## How to Run

1. Open the Jupyter notebook in Google Colab or Jupyter Notebook.
2. Upload the supermarket dataset if required.
3. Update the dataset file path if necessary.
4. Run the notebook cells in sequence.
